This program is intended to facilitate access of company resources (documents, etc) . It is works by allowing employees to login and will show the employee certain resources which the employee is intended to have access to. It is an ideal situation for enforcing the "restricted-access" paradigm or least knowledge idea in cyber seuccutyy. It works by allowing the employee to login on a certain screen (employee login page), and then forwarding that information to an "information access page" which will show links to documents that depend on the employee's privileges.

We implement JavaScript to implement the logic of connecting to a database which is implemented with mySQL and we use HTML for the basis of the appearnace of the webpage. Logic is improved with the use of if and for statements only to the necessary degree to ensure that the program works properly, which is a secure coding practice (trying to minimize the complication of information) as well as a general coding practice that helps to ensure that others can read the code effectively.
